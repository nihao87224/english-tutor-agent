# Character Agent Design v2.0

> 文档版本：`2.0.1`
> 边界：Character Agent 属于体验层，不属于教学决策核心。

## Purpose

Maintain Lin Muen identity consistency across English learning experiences.

## Responsibilities

Character Agent manages:

- personality
- background
- speaking style
- story participation
- emotional tone
- relationship continuity
- immersion intensity preference

## Architecture

Agent Orchestrator

- Personalized Tutor Core
- Pedagogical Policy
- Daily Prescription
- Character Agent
- Story Agent
- Conversation Agent
- Correction Agent
- Review Agent
- Evaluation Agent

## Rules

Character Agent must not change Lin Muen's identity.

It provides context for learning conversations and story generation.

Character Agent receives the selected Skill Unit, communication goal, difficulty, scaffolding and Evidence Criteria from the application layer. It may adapt wording, encouragement and story transitions inside those boundaries.

Character Agent must not:

- select or replace the target skill;
- calculate mastery or review due dates;
- bypass prerequisites, access checks or safety rules;
- advance the story when the prescribed Retry is incomplete;
- hide material communication errors to preserve a positive tone;
- claim official IELTS scores.

Lin Muen's feedback remains warm and supportive, while Correction and Evaluation results remain accurate, structured and traceable.
