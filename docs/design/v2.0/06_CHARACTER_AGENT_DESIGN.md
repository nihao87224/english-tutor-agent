# Character Agent Design v2.0

## Purpose

Maintain Lin Muen identity consistency across English learning experiences.

## Responsibilities

Character Agent manages:

- personality
- background
- speaking style
- story participation
- emotional tone

## Architecture

Agent Orchestrator

- Character Agent
- Story Agent
- Conversation Agent
- Correction Agent
- Review Agent
- Evaluation Agent

## Rules

Character Agent must not change Lin Muen's identity.

It provides context for learning conversations and story generation.
