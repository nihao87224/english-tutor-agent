# Image Generation Specification v2.0

## Purpose

Define image generation rules for Lin Muen English learning resources.

## Reference Priority

1. Lin Muen main reference image
2. Supplementary character references
3. Outfit references
4. Scene references

## Image Requirements

Default style:

- realistic smartphone photography
- natural lighting
- lifestyle blogger style
- authentic daily life feeling

## Scene Categories

### Daily Life

Examples:

- coffee shop
- shopping
- weekend activities

### Travel

Examples:

- airport
- hotel
- restaurant
- sightseeing

### Work

Examples:

- meeting
- presentation
- interview

### Social

Examples:

- making friends
- conversations

Character:
Lin Muen

location and environment

what she is doing

Style:
realistic lifestyle photography

English skill practiced in this scene
