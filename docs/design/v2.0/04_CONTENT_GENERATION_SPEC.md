# Content Generation Specification v2.0

## Goal

Generate immersive English learning resources based on Lin Muen stories.

## Required Elements

Every episode must contain:

- story background
- learning objective
- vocabulary
- useful expressions
- dialogue
- speaking mission
- review tasks
- image prompts
- audio scripts

## Principles

Do not generate isolated textbook lessons.

Every lesson must connect:

Lin Muen character + real scenario + communication goal + user practice.

## Generation Flow

1. Select episode scenario.
2. Define communication goal.
3. Create story.
4. Create dialogue.
5. Create practice tasks.
6. Create image and audio requirements.
7. Validate learning value.
