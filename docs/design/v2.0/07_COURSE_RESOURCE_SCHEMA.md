# Course Resource Schema v2.0

## Episode Resource

```json
{
  "episodeId": "EP001",
  "character": "Lin Muen",
  "story": {},
  "images": [],
  "audio": [],
  "dialogue": [],
  "practice": [],
  "reviewTasks": []
}
```

## Required Content

Each episode must provide:

- Story
- Visual assets
- Learning objectives
- Dialogue
- Speaking practice
- Review tasks

## Asset Metadata

Images and audio should contain:

- id
- version
- purpose
- generationPrompt
