## Adaptive Mapping Examples

### EP002 Coffee Shop Morning

| Learner state | Selected Skill Unit | Mission variation | Evidence |
|---|---|---|---|
| A2, polite request is weak | `service.order_drink.a2` | Help Lin Muen order one drink | order + size + polite request |
| B1, clarification is weak | `service.clarify_order.b1` | Confirm milk and sweetness options | asks + confirms + restates |
| B1, small talk is weak | `social.cafe_small_talk.b1` | Continue a short chat after ordering | responds + follow-up + closes |
| Skill already mastered | transfer variant | Resolve a wrong order in a new cafe | explains + negotiates solution |

### EP006 Airport Adventure

| Learner state | Selected Skill Unit | Mission variation | Evidence |
|---|---|---|---|
| A2 travel beginner | `travel.ask_direction.a2` | Find the check-in counter | asks location + follows direction |
| B1 listening weakness | `travel.confirm_information.b1` | Confirm a changed boarding gate | identifies key fact + confirms |
| B2 problem solving | `travel.handle_disruption.b2` | Discuss options after a delay | explains need + compares options + decides |

### EP009 Work Meeting

| Learner state | Selected Skill Unit | Mission variation | Evidence |
|---|---|---|---|
| B1 progress reporting weak | `work.report_progress.b1` | Help Lin Muen give a concise update | progress + blocker + next step |
| B1 clarification weak | `work.ask_clarification.b1` | Clarify an unclear request | checks meaning + confirms action |
| B2 opinion weak | `work.support_opinion.b2` | Recommend one content plan | opinion + reason + trade-off |

These mappings demonstrate the acceptance rule: the same Episode produces different training for different learner states, while Lin Muen's identity and story context remain consistent.
