# ADR-0001：第一版采用模块化单体

状态：Accepted

## Context

产品包含评估、画像、计划、训练、纠错、复习和 IELTS 等多个领域，但第一版团队规模和流量不需要微服务带来的部署与分布式复杂度。

## Decision

后端第一版作为一个可部署应用，内部按清晰业务模块划分，模块之间通过应用接口或领域事件协作。

## Consequences

优点：

- 本地开发和部署简单；
- 事务和调试清晰；
- 可快速交付纵向闭环。

约束：

- 严格控制模块依赖；
- 不允许通过“同一进程”随意跨模块读写表；
- 当出现独立扩容、组织边界或可靠性需求时再评估拆分。
