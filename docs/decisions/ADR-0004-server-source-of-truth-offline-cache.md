# ADR-0004：服务端维护长期事实，Android 使用离线优先缓存

状态：Accepted

## Context

学习者画像、掌握状态、复习调度和训练证据需要跨设备、一致且可审计。
Android 同时需要在弱网和进程重启时恢复页面与未完成操作。

## Decision

- 服务端数据库是长期学习事实的唯一权威来源；
- Android 使用 Room/DataStore 保存可恢复的本地缓存和待同步操作；
- 客户端缓存不得覆盖服务端已确认事实；
- 写操作使用幂等键、版本或服务端时间解决重复与冲突。

## Consequences

需要明确同步状态、冲突处理、重试和离线队列，但可以获得更可靠的移动端体验。
