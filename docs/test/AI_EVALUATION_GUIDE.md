# AI Evaluation Guide

## 1. Why

模型回复“看起来不错”不是质量标准。每次 Prompt、模型或路由变化都需要固定样本回归。

## 2. Evaluation dimensions

### Correction

- 是否发现真正错误；
- 是否避免过度纠错；
- corrected 是否自然且保留原意；
- severity 是否合理；
- shouldInterrupt 是否符合规则；
- 中文解释是否简洁。

### Planning

- 是否利用目标、画像、历史和可用时间；
- 不同用户是否得到不同计划；
- 是否满足时长预算；
- 是否包含到期复习；
- 安排原因是否可解释。

### Assessment

- 难度是否匹配自评；
- 是否采集四技能最小证据；
- 高自评是否增加开放表达；
- 结果是否包含置信度；
- 是否避免过度精确结论。

### IELTS

- 四维反馈是否有证据；
- 是否避免声称官方分数；
- 同一答案多次评分波动是否可接受；
- 建议是否可执行。

## 3. Change protocol

1. 固定模型、Prompt 版本和参数；
2. 运行基线样本；
3. 记录质量、延迟和成本；
4. 修改一个主要变量；
5. 重新运行；
6. 人工抽查失败和边界样本；
7. 仅在质量护栏满足时发布。
