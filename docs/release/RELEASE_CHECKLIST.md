# Release Checklist

## Product

- [ ] P0 验收场景通过
- [ ] 已知限制在发布说明中透明
- [ ] IELTS 参考评分免责声明可见

## Build

- [ ] 后端生产构建通过
- [ ] Android release 构建和签名通过
- [ ] 依赖漏洞检查完成
- [ ] 数据库迁移在生产副本验证

## Data and privacy

- [ ] 隐私默认值已确认
- [ ] 音频保存和过期策略有效
- [ ] 数据删除链路通过
- [ ] 日志脱敏抽查通过
- [ ] 生产密钥不在仓库

## Reliability

- [ ] 关键外部服务超时、重试和熔断已验证
- [ ] AI 结构化输出降级有效
- [ ] 弱网、断网和恢复路径验证
- [ ] 监控和告警生效

## Operations

- [ ] 部署步骤演练
- [ ] 回滚步骤演练
- [ ] 数据库变更回退/补偿策略明确
- [ ] 负责人和应急联系明确

## Evidence

- [ ] 测试报告
- [ ] Review 结果
- [ ] 发布版本和 Git Tag
- [ ] 变更日志
- [ ] 用户验收记录
