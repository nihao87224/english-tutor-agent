# Definition of Done

任何编码任务只有同时满足以下条件，才能标记为 `DONE`。

## 1. Product and scope

- 实现符合当前任务及 PRD。
- 未实现任务明确排除的内容。
- 未发生未记录的业务规则变化。
- 需求、设计和实现之间可以追踪。

## 2. Code

- 构建通过。
- 没有未解释的 TODO、临时绕过和硬编码密钥。
- 没有与任务无关的大范围重构。
- 新依赖已说明用途和影响。
- 代码符合模块边界和项目规则。
- 异常、空值、重复请求和权限路径已处理。

## 3. Data and contracts

- API 变更同步更新 OpenAPI。
- AI 输出变更同步更新 JSON Schema 和示例。
- 数据库变更包含新 Flyway 迁移。
- 已发布迁移未被修改。
- 事务和幂等策略明确。

## 4. Testing

- 新业务规则有单元测试。
- 关键持久化/API 边界有集成测试。
- 正常、边界和失败路径有覆盖。
- AI 测试默认使用固定 Fake Provider。
- 声明的测试命令已实际运行并通过。
- 不能运行的测试必须说明原因，任务不得直接标记完成。

## 5. Security and privacy

- 用户只能访问自己的资源。
- 不记录密钥、授权头和不必要的隐私数据。
- 音频上传限制类型、大小和时长。
- 隐私设置得到尊重。
- 数据删除相关变更有审计与测试。

## 6. Documentation

- 任务状态已更新。
- 变更日志已更新。
- 本地启动方式仍准确。
- 新决策已经写入 ADR。
- 遗留问题转为明确任务，而不是隐藏在代码注释中。

## 7. Review

- 已进行独立代码 Review。
- 所有 BLOCKER/HIGH 问题已解决。
- Diff 已人工逐文件检查。
- 无意外删除或二进制文件。
