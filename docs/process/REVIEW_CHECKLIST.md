# Review Checklist

## A. Scope

- [ ] 只修改当前任务相关内容
- [ ] 没有未经说明的重构
- [ ] 没有删除现有功能或契约
- [ ] 新抽象当前确实被使用

## B. Product correctness

- [ ] 满足任务验收标准
- [ ] 与 PRD 业务规则一致
- [ ] Agent 自动规划原则未被破坏
- [ ] 语音、纠错、评估的用户体验符合设计

## C. Architecture

- [ ] 模块依赖方向正确
- [ ] Controller/Composable 无业务或数据访问逻辑
- [ ] 供应商 SDK 未泄漏到业务层
- [ ] 确定性规则没有完全交给 LLM
- [ ] 没有不必要地引入微服务或消息中间件

## D. Correctness and resilience

- [ ] 空值、边界和非法状态已处理
- [ ] 写操作考虑幂等
- [ ] 并发生成今日计划不会重复
- [ ] 事务边界清晰
- [ ] 外部服务超时和失败可恢复
- [ ] AI 非 JSON/字段缺失有降级
- [ ] Android 弱网和进程恢复有合理处理

## E. Security and privacy

- [ ] 所有用户资源有归属校验
- [ ] 日志不含密钥和敏感原文
- [ ] 音频校验类型、大小和时长
- [ ] 隐私设置影响真实保存行为
- [ ] 删除流程覆盖数据库与对象存储

## F. Contracts and data

- [ ] OpenAPI 与实现一致
- [ ] JSON Schema 与模型输出一致
- [ ] Flyway 迁移可在空库执行
- [ ] 唯一键和索引有明确业务用途
- [ ] Redis Key 有 TTL 与失效策略

## G. Tests

- [ ] 测试验证业务行为而非实现细节
- [ ] 正常、失败、权限和重复请求有覆盖
- [ ] AI 测试可确定性重复
- [ ] 测试命令和结果真实记录
- [ ] 没有通过删除断言来“修复”测试
