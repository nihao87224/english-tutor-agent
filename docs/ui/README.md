# English Tutor Agent UI 交互原型

## 使用方式

直接双击打开：

- `english-tutor-agent-ui-prototype-v1.html`

文件为单页自包含 HTML，不需要安装依赖，也不需要联网。

## 原型覆盖流程

1. 欢迎页与唯一目标选择
2. 听说读写自评
3. 8–10 分钟轻量能力初评
4. 初始多维能力画像
5. Agent 自动生成今日学习计划
6. 分级听力到口语训练
7. 语音回答和分层纠错
8. 训练总结和后续计划调整
9. 能力趋势与掌握状态
10. IELTS Speaking Part 2 样例
11. 当天临时计划调整

## 交互说明

- 左侧导航可切换所有页面。
- 首页“调整今天”可打开临时需求面板。
- 听力页可播放模拟音频进度、显示或隐藏关键词。
- 语音页点击麦克风可模拟 5 秒录音、识别和纠错。
- IELTS 页面可启动准备倒计时。

## 定位

该文件用于产品 UI 与交互方向确认，不代表最终 Android 实现细节。
