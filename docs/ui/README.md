# English Tutor Agent UI 交互原型

## 使用方式

V1.0 表达教练原型可直接双击打开：

- `english-tutor-agent-ui-prototype-v1.html`

V1.1.0 SaaS Foundation 原型可直接双击打开：

- `ENGLISH_TUTOR_AGENT_SAAS_UI_PROTOTYPE_v1.1.0.html`

文件为单页自包含 HTML，不需要安装依赖，也不需要联网。

## 原型覆盖流程

1. 欢迎页与唯一目标选择
2. 听说读写自评
3. 8–10 分钟轻量能力初评
4. 初始多维能力画像
5. Agent 自动生成今日学习计划
6. Web 今日表达教练
7. 文字表达、流式回复和分层纠错
8. 训练总结和后续计划调整
9. 能力趋势与掌握状态
10. 后续 IELTS Speaking 样例
11. 当天临时计划调整

## V1.1.0 SaaS 原型覆盖流程

1. 登录与注册
2. Web Learner 今日页、练习页、历史、进度、账号与额度
3. 每日 AI 请求额度展示与额度耗尽状态
4. Web Admin Overview
5. 用户管理、状态启停和额度调整弹窗
6. AI Provider 运行时配置和密钥掩码
7. 系统设置
8. 审计日志
9. zh-CN / en 切换
10. 桌面与 390px 移动视口预览

## 交互说明

- 左侧导航可切换所有页面。
- 首页“调整今天”可打开临时需求面板。
- 表达教练页展示今日目标、可复用表达结构和输入任务。
- 对话页模拟 SSE 流式回复、`correction_ready` 纠错面板和 Try Again。
- IELTS、语音和听力页面仅作为后续阶段概念，不是 V1.0 发布门槛。

## 定位

这些文件用于产品 UI 与交互方向确认。V1.0 原型以 Web 表达教练为主；
V1.1.0 原型以 SaaS 身份、额度、管理后台和运行时配置为主。
原型不代表最终 Android 实现细节，也不代表生产数据来源。
